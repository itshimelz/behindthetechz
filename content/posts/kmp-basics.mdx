**Kotlin Multiplatform (KMP)** বর্তমানে মোবাইল অ্যাপ ডেভেলপারদের মধ্যে বেশ জনপ্রিয়। এর প্রধান কারণ হলো আপনি একটি মাত্র কোডবেস লিখে একই সাথে Android এবং iOS-এ অ্যাপ তৈরি করতে পারবেন।

### কেন KMP ব্যবহার করবেন?

KMP-এর সবচেয়ে বড় সুবিধা হলো এটি শুধু লজিক শেয়ার করে, কিন্তু UI প্রতিটি প্ল্যাটফর্মের নিজস্ব (Native) টুল ব্যবহার করে তৈরি করতে দেয়।

```kotlin
// shared/src/commonMain/kotlin/Greeting.kt
class Greeting {
    fun greet(): String {
        return "হ্যালো, KMP ওয়ার্ল্ড!"
    }
}
```

এছাড়াও, বর্তমানে [[ai-intro-bd]] এর মতো টেকনোলজির যুগে আর্টিফিশিয়াল ইন্টেলিজেন্স ব্যবহার করে এই ধরনের মাল্টিপ্ল্যাটফর্ম কোড আরো দ্রুত লেখা সম্ভব।

### প্রয়োজনীয় টুলস

KMP নিয়ে কাজ শুরু করতে আপনার প্রয়োজন হবে:

1. Android Studio
2. Xcode (ম্যাকের জন্য)

আপনি যদি আরো গভীরে যেতে চান, তবে পরবর্তী সময়ে আমরা কিভাবে KMP এর সাথে [[mastering-nextjs-app-router]] দিয়ে একটি ওয়েব ইন্টারফেস জোড়া দেওয়া যায় সেটা নিয়ে আলোচনা করবো।
