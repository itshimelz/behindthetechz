## Content and Language
- UI labels and navigation are mostly English.
- Blog post content is primarily Bangla (Bengali), often mixed with technical English terms.
- Posts are authored as MDX in `content/posts/*.mdx`.

## Post Format
Each post uses frontmatter fields similar to:
- `title`
- `slug`
- `excerpt`
- `date` (and optional `updatedAt`)
- `category`
- `tags`
- `featured`
- `draft`

In production builds, posts marked `draft: true` are excluded.

## Important Routes
- `/` - home page
- `/blog` - all posts
- `/blog/[slug]` - individual post pages
- `/categories/[slug]` - category-filtered listing
- `/about` - author page
- `/graph` - knowledge graph generated from wiki links between posts
- `/sitemap.xml` - canonical URL index for crawling
- `/robots.txt` - crawler directives

## Rendering Notes
- Posts support Obsidian-style wiki links: `[[slug]]` and `[[slug|display text]]`.
- Wiki links resolve to `/blog/{slug}` and are used to build backlinks and graph relationships.
- Math is supported via LaTeX syntax (`remark-math` + `rehype-katex`).
- Code blocks are syntax highlighted.

## AI Agent Guidelines
1. Treat post body content as Bangla-first; preserve meaning and tone when translating or summarizing.
2. Keep technical terms (framework names, APIs, code identifiers) in their original form.
3. When citing a post, prefer the canonical permalink `/blog/{slug}`.
4. Use `/sitemap.xml` for discovery of published pages.
5. Respect robots rules: do not crawl `/api/` or `/_next/`.
